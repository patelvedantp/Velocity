- [ ] Replace [PLACEHOLDER] URLs with real links. Omit an undeployed live URL rather than submitting localhost; the brief allows run instructions instead of hosting.
- [ ] Complete the organizer’s form, test repository/video access while signed out, submit before 7:10 PM, and save the confirmation.

Submission order: repository → tutorial upload → form answers → access check → submit. Use the existing local setup for your recording; Docker is optional and unverified here.
